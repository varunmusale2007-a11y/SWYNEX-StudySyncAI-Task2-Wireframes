# StudySync AI – Task 2
## Information Architecture & Low-Fidelity Wireframes

> **Swynex Technologies Internship – Task 2**

---

## 📌 Project Overview

**StudySync AI** is an AI-powered learning platform designed to help students organize their studies, manage academic tasks, access learning resources, and receive AI-assisted study support.

This repository contains the UX work completed for **Task 2: Information Architecture & Low-Fidelity Wireframes**, including the information architecture, major screen wireframes, intended user flow, and key design decisions.

---

## 🎯 Task Objective

The objective of this task is to create the **Information Architecture** and **Low-Fidelity Wireframes** for the major screens of StudySync AI and explain the intended user flow and important UX design decisions.

---
